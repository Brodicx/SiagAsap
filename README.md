# SiagAsap

Aplikasi web untuk membantu masyarakat menghadapi kebakaran hutan dan lahan (karhutla).

**Situs:** https://siagasap.setiawanhadi.my.id/

## Kegunaan

Saat karhutla terjadi, warga membutuhkan informasi cepat: seberapa buruk kualitas udara di sekitarnya, ke mana melaporkan titik api, dan di mana mendapatkan bantuan medis. SiagAsap menyatukan ketiganya dalam satu aplikasi sehingga masyarakat dapat bersiaga dan bertindak lebih cepat.

## Fitur

- **Estimasi kualitas udara:** memantau perkiraan kualitas udara di sekitar pengguna.
- **Lapor titik api:** warga dapat melaporkan titik api beserta lokasi, tingkat kepekatan asap, dan nomor WhatsApp pelapor. Setiap laporan memiliki status penanganan.
- **Posko medis:** mencari posko kesehatan beserta lokasi, kontak, dan ketersediaan stok barang.
- **Akun pengguna:** pengguna terdaftar dengan peran (`role`), bawaan `Warga`.
